# DEV-058 — zemljevid in diskretne izboljšave geografskega iskanja

Izhodišče: `main` / `1b952cb56619c4a9cb3bb28fa977dbb44e893eff`, združeni DEV-056 / PR #267. Namen je pregled prek Draft PR, brez mergea ali deploymenta.

Preflight 13. 11. 2026: produkcijski Finder vrne HTTP 200 in uporablja DEV-056; Cloudflare Pages check na izhodiščnem main je uspešen. Odprti PR #266 (starejša raziskava DEV-056), #247 (GPX) in #237 (dokumentacija) ne posegajo v to nalogo. Profila SL/EN sta zemljevid doslej odprla z besedilom kraj + regija. Pregledani so bili kartice, filtri, opozorila in obstoječe regresije.

Sveži `npm run nearby:coverage` bere samo javni Worker API: 93 javnih prihodnjih potrjenih izvedb, 86 z lokacijo (1 potrjen štart, 85 približnih), 7 brez lokacije. Leta 2026 manjkata 2 od 26, leta 2027 pa 5 od 67. Geografski katalog in odobritve so nespremenjeni.

Spremembe:

- Profila uporabljata `NEARBY_EDITION_LOCATIONS` iz produkcijskega indeksa. Skupni resolver ponovno uporabi `indexByEdition`, `usableEditionStarts`, preverjanje vlog štartov in `isApprovedLocation`. Preveri leto, Master vrstico, datum, izvorni naziv, kraj in regijo. Stara ali manjkajoča identiteta ohrani besedilno poizvedbo Google Maps.
- Potrjen štart odpre svojo koordinato. Približna referenca odpre svojo koordinato s pojasnilom, da ni potrjen štart ali točka prihoda. Več različnih natančnih štartov se ne združi v izmišljen skupni pin. `map_click`, HTTPS, `target` in `rel` ostanejo ohranjeni.
- Finder ob razdalji pokaže `Potrjen štart` / `Verified start` ali `Približna lokacija` / `Approximate location`. Nadomesti daljšo staro opombo in ponovljeno krajevno oznako. Sekundarna tipografija uporablja obstoječo nevtralno barvo; na ozkem zaslonu se skupina po potrebi prelomi. Ni nove značke ali obvezne nove vrstice na vsaki kartici.
- Native `details/summary` pod opozorilom pokaže dejanske dogodke brez uporabne lokacije. `summarizeNearbyCoverage` določi manjkajoče identitete; seznam se nato preseka s trenutnimi negeografskimi filtri pred uporabo radija. Opozorilo še vedno opisuje pokritost celotnega ustreznega nabora, številka ob kontrolniku pa trenutni seznam. Prazen seznam se skrije. Datum, naziv, kraj in povezava so ločeni od kartic zadetkov; prikaz uporablja DOM `textContent` in obstoječi gradnik lokalnih profilnih poti.

Google Sheets, Content API, identitete, GPS zasebnost, radiji, razvrščanje in pravila za koordinate ostanejo nespremenjeni. Brez novih knjižnic, geokodiranja, zemljevida ali infrastrukture.
